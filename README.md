A make.fun bounty entry. The whole internet, described in a single word:

## Clownshow

Every feed is a parade of clowns performing for strangers, every argument
a pie fight, every timeline a ringmaster shouting "look at this". It makes
you laugh first and nod second: funny by itself, true of the whole internet
rather than one app, and not the obvious word everyone else reaches for.

## Run

```sh
node main.ts
```

The program writes the word to `/output/entry.txt` (override with the
`OUTPUT_DIR` environment variable). No network, no dependencies, no input:
the output is deterministic — the same word, byte for byte, every run.

Gate check: UTF-8 text, 1–30 characters, not only whitespace. This entry
is 9 characters, one word, no whitespace.
